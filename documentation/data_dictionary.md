# Sales Performance Analysis — Data Dictionary

## 1. Dataset Overview

The dataset contains retail sales transactions, including information about orders, customers, products, locations, shipping, sales, discounts, and profit.

The primary table used in the project is:

```text
Orders
```

Each row represents a transaction line associated with an order and product.

# 5. Date Table Usage

The Date table is connected to the Orders table using:

```text
DateTable[Date]
        │
        │ 1 : *
        ▼
Orders[Order Date]
```

The Date table is used for:

- Monthly trends
- Quarterly trends
- Yearly trends
- Year-over-year analysis
- Time-series visualizations

# 6. Important Measures

The following measures are calculated from the dataset.

### Total Sales

```DAX
Total Sales =
SUM(Orders[Sales])
```

### Total Profit

```DAX
Total Profit =
SUM(Orders[Profit])
```

### Total Orders

```DAX
Total Orders =
DISTINCTCOUNT(Orders[Order ID])
```

### Total Customers

```DAX
Total Customers =
DISTINCTCOUNT(Orders[Customer ID])
```

### Total Quantity

```DAX
Total Quantity =
SUM(Orders[Quantity])
```

### Profit Margin

```DAX
Profit Margin =
DIVIDE(
    [Total Profit],
    [Total Sales],
    0
)
```

### Average Order Value

```DAX
Average Order Value =
DIVIDE(
    [Total Sales],
    [Total Orders],
    0
)
```

# 7. Data Quality Considerations

### Missing Values

Check important fields such as:

```text

Check for duplicate order/product combinations and determine whether they represent legitimate transaction lines or duplicate records.

```

# 8. Business Definitions

### Sales

The revenue amount associated with a transaction.

### Profit

The profit associated with a transaction after the costs represented in the dataset.

### Profit Margin

The percentage of sales represented by profit.

```text
Profit Margin = Profit / Sales
```

### Average Order Value

The average sales value generated per unique order.

```text
AOV = Total Sales / Total Orders
```

### Year-over-Year Growth

Measures the percentage change between the current period and the corresponding previous-year period.

```text
YoY % =
(Current Period - Previous Year)
/
Previous Year
```
